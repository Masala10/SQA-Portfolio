# Manual Testing Portfolio - E-commerce Web Application

This repository contains my complete manual testing documentation for an E-commerce Web Application.
It includes Test Plan, Test Cases, and Bug Reports to demonstrate end-to-end QA process.

## 📁 Repository Structure

| File/Folder | Description |
| --- | --- |
| `TEST_PLAN.docx` | Master test plan covering scope, approach, risks, and deliverables |
| `Manual-Project_TestCases.xlsx` | Detailed test cases with steps, test data, and expected results |
| `/evidence/` | Screenshots and proof for all reported bugs |
| `README.md` | This file |

## 🎯 Project Overview
**Application**: E-commerce Web Application  
**Testing Type**: Manual Testing  
**Scope**: Functional, UI, Usability, Checkout Flow, User Profile  
**Tools Used**: Excel, Word, Browser, Postman for API

## 📋 Deliverables Included

### 1. Test Plan - `TEST_PLAN.docx`
Covers:
- **Test Objectives**: What we are testing and why
- **Scope**: In-scope and Out-of-scope features
- **Test Strategy**: Types of testing performed - Functional, UI, Regression
- **Risks & Assumptions**: Potential risks during testing
- **Roles & Responsibilities**: QA responsibilities
- **Entry/Exit Criteria**: When to start and stop testing

### 2. Test Cases - `Manual-Project_TestCases.xlsx`
Contains:
- **Test Case ID**: Unique ID for traceability
- **Module**: Feature area like Login, Cart, Checkout, Profile
- **Test Scenario**: High level what we are testing
- **Test Steps**: Step by step actions
- **Test Data**: Input data used
- **Expected Result**: What should happen
- **Status**: Pass/Fail
- **Priority**: High/Medium/Low
